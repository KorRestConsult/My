# Илья · Life OS

Статический прототип личной операционной системы в стиле RPG-панели, премиального чеклиста и мобильной штаб-квартиры.

## Что внутри

- Главная панель персонажа
- RPG-характеристики
- Чеклист дня: утро, день, вечер
- Дневник привычек на 1000 боксов
- Проекты
- Библиотека знаний
- Мужской кабинет
- Финансы
- Резюме: 3 слота для загрузки, скачивания и печати
- Авто: паспорт машины, ТО, ремонт, сканы документов
- Здоровье: история болезни, лечение, фото/анализы, врачи и контакты
- Интеграции: дорожная карта Apple Calendar/Minical, Reminders, Health, Mist и Money Flow
- Карта жизни и наследие
- Заготовки под AI, календарь, питание/Mist и Money Flow
- Пользовательское добавление привычек, напоминаний, заметок, файлов и записей без правки кода
- Главный экран дня: привычки, дела, календарь, цели, шаги и общий прогресс
- Firebase-ready слой: локальный режим работает сразу, Firestore включается после добавления config

## Запуск

Открой `index.html` в браузере или запусти локальный сервер:

```bash
python3 -m http.server 8000
```

После этого страница будет доступна на `http://localhost:8000`.

Состояние чеклистов, боксов, заметок, загруженных файлов и записей сохраняется в `localStorage` браузера.

Важно: это первая локальная версия. Для больших файлов, синхронизации между устройствами и настоящих интеграций нужен backend или облачное хранилище.

## Firebase

Сейчас приложение работает в локальном режиме. Чтобы включить Firebase:

1. Создай Firebase project.
2. Включи Authentication с Anonymous sign-in.
3. Создай Firestore Database.
4. Возьми web app config из Firebase Console.
5. В `index.html` замени `window.LIFE_OS_FIREBASE_CONFIG=null;` на объект config.

После этого состояние будет сохраняться в Firestore в документ:

```text
users/{anonymousUserId}/lifeos/state
```

## Apple Calendar, Minical и Reminders

Minical читает системный календарь Apple, поэтому веб-сайт должен получать данные через мост:

- самый быстрый путь: Apple Shortcuts экспортирует сегодняшние события и напоминания в JSON;
- следующий шаг: Shortcut отправляет JSON в Firebase;
- после этого главный экран показывает реальные дела и календарь за сегодня.

## Панель дня / Секретарь

Главный экран умеет читать единый JSON-контракт `secretary-snapshot`.

Порядок источников:

1. `window.LIFE_OS_SECRETARY_CONFIG.snapshotUrl` из `data/secretary-config.js`.
2. Локальный fallback `data/secretary-snapshot.sample.json`.
3. Пустое offline-состояние, если JSON недоступен.

Пример `data/secretary-config.js`:

```js
window.LIFE_OS_SECRETARY_CONFIG = {
  snapshotUrl: "https://example.com/secretary-snapshot.json",
  headers: {
    Authorization: "Bearer TOKEN"
  }
};
```

Для GPT-штаба рабочая схема такая: GPT ведет Google Sheets по вкладкам, отдельный Apps Script/backend собирает эти вкладки в один `secretary-snapshot`, сайт читает только готовый JSON.

## Финансы из Google Sheets

Экран `Финансы` читает Google Sheets через `data/secretary-config.js`.

Сейчас подключены:

- `Финансы`, `gid=1009` — основная лента операций.
- `Счета` — отдельный источник балансов счетов.
- `Долги` — отдельный источник долгов.
- `Финансовые цели` — отдельный источник целей накопления.

Если в `data/secretary-config.js` задан `finance.spreadsheetId`, сайт сам пробует открыть вкладки по именам через Google `gviz`. Явный URL в `finance.tabs` имеет приоритет и нужен только для нестандартного `gid` или другого источника. Финансовый экран обновляется при загрузке, при возврате вкладки браузера в фокус и по таймеру `finance.autoRefreshMs`.

Ожидаемые колонки вкладки `Финансы`:

```text
Дата, Тип, Категория, Подкатегория, Сумма, Валюта, Счет, Контрагент,
Проект/объект, План/факт, Регулярный, Документ, Комментарий, Источник, Статус, ID
```

Сайт сам считает:

- доход сегодня;
- расход сегодня;
- доход и расход за текущий месяц;
- общий капитал по вкладке `Счета`;
- платежи на контроле;
- долги из вкладки `Долги`, если она есть;
- финансовые цели из вкладки `Финансовые цели`, если она есть.

Ожидаемые колонки вкладки `Счета`:

```text
Счет, Тип, Баланс, Валюта, Граммы, Цена_грамм
```

Ожидаемые колонки вкладки `Долги`:

```text
Направление, Кто, Сумма, Остаток, Оплачено, Дата, Дата_возврата, Статус
```

Для `Направление` подойдут значения вроде `Я должен`, `Мне должны`, `Взял`, `Дал`.

Ожидаемые колонки вкладки `Финансовые цели`:

```text
Название, Цель_сумма, Накоплено, Осталось, Срок, Статус
```

Для приватной таблицы прямой Google `gviz` URL работает, если у браузера есть доступ к таблице. Если доступ начнет упираться в CORS/авторизацию, следующий шаг — заменить URL вкладок на Apps Script endpoint или backend, который отдает те же CSV/JSON.
